# GitHub repo memory protocol

Use a GitHub repository as **curated, versioned project memory** for AI-assisted work (ChatGPT, Claude, Codex, Cursor, Copilot, etc.).

| File | Use |
|------|-----|
| [AI_MEMORY_PROTOCOL.md](AI_MEMORY_PROTOCOL.md) | Full protocol — copy into any repo as `.memory/AI_MEMORY_PROTOCOL.md` or paste into a custom GPT / agent system prompt |
| [custom-instructions-short.md](custom-instructions-short.md) | Short version for ChatGPT **Custom Instructions** |

## Share links (public repo)

After this repository is public on GitHub, share the rendered or raw URLs, for example:

```text
https://github.com/DeepSpringAI/prompts/blob/main/github-repo-memory/AI_MEMORY_PROTOCOL.md
https://raw.githubusercontent.com/DeepSpringAI/prompts/main/github-repo-memory/AI_MEMORY_PROTOCOL.md
https://github.com/DeepSpringAI/prompts/blob/main/github-repo-memory/custom-instructions-short.md
```
