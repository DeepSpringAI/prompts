### Goal
Continue building the EHR UI after MainReport.vue.

**In this step we want:**

1. A **generic, reusable section component** that knows how to  
   • fetch its slice of JSON (or fall back to /sampleReport.json in dev)  
   • render the JSON tree into real controls (checkbox, text field, nested dropdown)  
   • expose `async saveData()` to persist changes (stub in DEV_MODE)  
   • emit `ready` when initial render is complete.
2. A **RecursiveDropdown.vue** helper that traverses `item.content[]` recursively and renders:
   * **dropdown** – collapsible panel with header and body  
   * **checkbox** – tick-mark + label (toggles `isChecked`)  
   * **text** – read-only line or free-text input (if `input` key present)
3. Three concrete section wrappers – **HPI.vue, SLP.vue, ObjectiveExam.vue** – each just sets its `sectionCode` prop and re-uses the generic section.
4. Updated **MainReport.vue** import paths to point at those new sections.
5. A **fresh e2e spec** that visits *HPI → toggle a checkbox → Save → Next → SLP* and asserts the checkbox state persisted in memory.

### Output rules
* Return **multiple files**.  
* Delimit each file with: `--- FILE: <relative-path/filename> ---`  
* After the final file, **stop** – no commentary.

### Files to generate / update
1. **src/components/RecursiveDropdown.vue**  
   * `<script setup lang="ts">` – Composition API.  
   * Accepts `item`, `onInput`, `onToggle` props.  
   * Uses `v-show` for dropdown bodies; `@click` for checkboxes.  
   * All styling via Tailwind (simple gray border, bold header, indent children).

2. **src/components/BaseSection.vue**  
   * Props: `reportId: number`, `sectionCode: string`.  
   * Local refs: `formData`, `isReady`.  
   * `onMounted` → `fetchSection()` helper (import from `@/utils/fetchSection`).  
   * Renders `<RecursiveDropdown v-for="it in formData" :key="it.id" .../>`.  
   * Provides `async saveData()`; if `DEV_MODE` resolves immediately; otherwise posts to `/api/saveReport`.  
   * Emits `"ready"` when `isReady` flips true.

3. **src/components/sections/HPI.vue**  
   * Wrapper that imports and re-exports `<BaseSection sectionCode="HPI" />`.

   *(repeat for SLP.vue and ObjectiveExam.vue)*

4. **src/components/MainReport.vue**  
   * Update imports to `sections/HPI.vue`, `sections/SLP.vue`, `sections/ObjectiveExam.vue`.

5. **tests/e2e/SectionFlow.spec.ts**  
   * Visit root.  
   * Wait for text `"History of Present Illness"` to be visible (from HPI sample).  
   * Click the checkbox with label `"Onset ≤ 24 h"`.  
   * Click **Save** then **Next**.  
   * Assert SLP tab is active and checkbox state remains true when you click Back.

### Coding conventions
* Strict TypeScript everywhere.  
* No inline comments inside JSON.  
* Use ESM import syntax.  
* Tailwind for layout; avoid custom CSS.
